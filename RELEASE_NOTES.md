# Glass UI v1.0

First numbered public release package: coordinated glass styling for deck lists and overviews, configurable colours and sizing, readable deck highlights, fixed Segoe UI typography, and immediate Apply/Save controls.

Install the `.ankiaddon` file using Tools → Add-ons → Install from file, then restart Anki.

Automated checks pass. Runtime performance and compatibility across Anki versions and third-party add-ons are not yet certified.
