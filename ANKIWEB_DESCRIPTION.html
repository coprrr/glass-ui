Glass UI 1.0

A configurable glass-style theme for Anki's deck list and deck overview.

  • Dark, light, or match-Anki appearance
  • Adjustable opacity, blur, rounding, colours, text size and spacing
  • Coordinated deck panels and Study Now button
  • Simple settings window with immediate Apply

After installation, restart Anki and open Tools → Add-ons → Glass UI → Config. Enable Glass UI and click Apply.

Wallpaper is not included. Continue using your preferred background add-on. Card templates, native dialogs and the separate congratulations screen are not themed. Third-party calendar styling can vary.

Designed for Qt 6 Anki desktop. A tested-version compatibility matrix has not yet been established. For lower graphics cost, set blur to 0px.
